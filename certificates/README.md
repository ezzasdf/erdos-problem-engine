# EMVE Portable Verification Certificates (`emve-cert-v1`)

This directory contains standalone, portable mathematical verification certificates generated by the **Erdős Mathematical Verification Engine (EMVE)**.

---

## 1. Key Design Principle: Zero-Trust Decoupled Verification

A recipient does **not** need to trust or run EMVE's combinatorial breadth-first search engine, carry-automata generators, or heuristics. 

Anyone can download a `.json` certificate and verify it from first principles in milliseconds using the independent auditor:

```bash
# Fast standalone audit (validates mathematical properties of matrix in JSON)
python3 scripts/check_certificate.py certificates/M19_collatz_wielandt.json

# Audit all certificates in directory
python3 scripts/check_certificate.py certificates/*.json

# Optional end-to-end check (also verifies matrix derivation from multiplier M)
python3 scripts/check_certificate.py --verify-derivation certificates/*.json
```

---

## 2. Certificate Schema Specification (`emve-cert-v1`)

Each certificate is a self-contained JSON document containing:

| Field | Description |
| :--- | :--- |
| `format_version` | Specification version (`"emve-cert-v1"`). |
| `certificate_type` | Verification type: `"collatz_wielandt"` (integer vector inequality) or `"sturm_root_count"` (exact roots in $\mathbb{Q}(\sqrt{5})$). |
| `problem_id` | Unambiguous domain identifier (e.g. `erdos-cantor-multiplier:M=19:family=2:lag=(1,3)`). |
| `mathematical_context`| High-level mathematical metadata (multiplier, family, forward lag, graph type). |
| `claim` | The formal mathematical property being certified, including exact inequality and rational bounds. |
| `witness` | The raw mathematical witness: matrix dimensions, full transition matrix entries $A \in \mathbb{Z}_{\ge 0}^{n \times n}$, and integer vector $v \in \mathbb{Z}_{>0}^n$. |
| `metadata` | Generator information, Zenodo archive DOI (`10.5281/zenodo.24595631`), and UTC timestamp. |
| `payload_sha256` | Mandatory 64-character hexadecimal SHA-256 integrity checksum of canonical payload JSON. |

---

## 3. Trust Boundaries & Important Limitations

To maintain rigorous scientific standards, the auditor enforces explicit trust boundaries:

### A. Integrity Checksum vs. Authenticity
- The `payload_sha256` field functions as an **integrity checksum** to detect accidental bit flips, incomplete downloads, or file corruption.
- It is **strictly enforced**: missing, empty, or mismatched checksums are immediately rejected.
- **Authenticity Limit:** A SHA-256 hash does *not* prove author identity or prevent deliberate re-hashing of modified files. Authenticity must be verified out-of-band against signed Git release tags or the official Zenodo archive record ([DOI: 10.5281/zenodo.24595631](https://zenodo.org/records/24595631)).

### B. The Three-Level Verification Hierarchy
We distinguish three distinct levels of verification:
1. **Level 1 (Verified Certificate):** Proves an exact mathematical property ($5Av \le 8v$ or $\rho(A)=\phi$) of the supplied matrix $A$. 100% independent of graph generation code and search heuristics.
2. **Level 2 (Verified Derivation):** Proves that the supplied matrix and metadata strictly match the project's canonical carry automaton generator (`--verify-derivation`). *Notice:* This proves agreement with the generator code; it does not independently prove the generator algorithm faithfully models the continuous Cantor problem.
3. **Level 3 (Full Theorem Target / Conditional Mathematical Conclusion):** The universal dimension bound on $\mathbb{R}$ is proved unconditionally for boundary rays and proven extremizers, but remains **conditional on Hypothesis (H)** in the interior domain, with an analytical Frostman measure bridge.

### C. Third-Party Dependencies
- **Collatz–Wielandt:** Completely self-contained with **zero external dependencies** (runs on stock Python 3 standard library; SymPy is not imported).
- **Sturm Sequence Root Counter:** Independent of EMVE's search heuristics, but lazily imports **SymPy** for characteristic polynomial calculation and Sturm polynomial remainder chains. Root isolation signs are evaluated in exact quadratic field arithmetic $\mathbb{Q}(\sqrt{5})$.

### D. Strict Integer Typing
- Because Python treats `bool` as a subclass of `int` (`isinstance(True, int) == True`), the auditor explicitly rejects boolean values in matrix entries $A_{ij}$ and witness vector entries $v_i$.
